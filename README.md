# ALMJ — Artificial Jewelry

A responsive, mobile-friendly storefront landing page for ALMJ Artificial Jewelry.

## Live website
Once GitHub Pages finishes publishing, visit: https://aliflaammeemjewellers.github.io/ALMJ/

## Update the site
Edit `index.html` directly on GitHub. The website is a static HTML page and needs no build step. Product imagery is loaded from Unsplash; replace image URLs with your own product photos whenever ready.

## Contact
WhatsApp ordering, social links and email are included in the page.
